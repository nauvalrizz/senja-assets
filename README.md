## dutch_ship_medium_2k.glb (27.7 MB)

[Poly Haven](https://polyhaven.com/a/dutch_ship_medium), licensed
[CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/)
(no attribution required, included here as courtesy).

Packed to single GLB (2K PBR textures embedded) from Poly Haven's glTF
download with gltf-transform. Original: 69K tris, ~24.7m tall, Y-up.
